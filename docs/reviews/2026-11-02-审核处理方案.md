# 2026-11-02 设计审核处理方案

> 对应 PR：`#1 docs: 题目二完整设计审核意见`
> 结论：R01–R12 全部采纳。本文是修改与验收的追踪表；规则变更以本文列出的文档为准。

## 1. 处理原则

1. 先改规则与契约，再改工作包，最后改代码。
2. 每条问题都要有可复现的回归用例，不能只改文字。
3. JEVDB 从“可选加速”改为“最终验收硬门槛”；开发期仍允许 `jev_direct`。
4. 风险与账本规则以“真实组合、真实时间”为准，不为计算方便删数据。
