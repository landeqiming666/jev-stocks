# CR-20261102-w01-unknown-check-step

- 提出者：W-01 测试准备。
- 类型：共享检查入口问题。
- 状态：草案，待协调者分派；未修改共享实现。

## 现象

W-01 §8.1 要求 `check.ps1 --only no-such-step` 非零退出，但当前共享入口直接执行：

```text
py -3 scripts/check.py --only no-such-step
通过 0 · 失败 0 · 跳过 17
退出码：0
```

包装器若正确原样传播退出码，只能得到 0。当前占位 `.ps1` 恰好退出 1，可能让错误的验收用例假通过。

## 方案与测试

1. 共享 check.py 在执行前验证 `--only` 名称，未知项给出明确错误并非零退出；包装器保持原样传播。影响共享入口与检查脚本测试。
2. 若设计本来允许未知名称，则同步调整 W-01 的对应预期；退出码透传改由受控 Python 程序明确返回 7/23 验证。

准备测试已把两件事分开：真实包装器副本调用临时 Python 程序，校验返回码及参数；另有用例直接验证共享入口拒绝未知步骤。
