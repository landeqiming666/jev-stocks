# CR-20261102-w01-acl-contract

- 提出者：W-01 测试准备。
- 类型：规范与参考命令不一致。
- 状态：草案，待协调者决定；未修改平台实现。

## 问题与实测

W-01 §5.1 要求 `harden_permissions` “只保留当前用户的完全控制”，但参考命令：

```text
icacls <path> /inheritance:r /grant:r *<当前用户SID>:(OI)(CI)F
```

仅删除继承 ACE，并替换指定 SID 的显式授权，其他 SID 的显式授权不会被删除。[icacls 官方语义](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/icacls)

已在本次新建的空临时目录实测：预先显式授予以下三个 SID 读取权限，执行参考命令后，三项仍全部存在：

- `S-1-1-0`（Everyone）；
- `S-1-5-32-545`（Users）；
- `S-1-5-11`（Authenticated Users）。

当前用户权限保留，临时夹具已清理，没有改动真实数据目录。

## 需要决定

1. **严格的当前用户专用 DACL**：重建目标 DACL，只留下当前用户需要的授权，并明确处理已有显式拒绝 ACE。影响平台实现与较强的安全断言。
2. **仅清除指定广泛主体**：明确列出必须移除的 SID，以及允许保留的 SYSTEM、Administrators 或其他主体；同步改写“只保留当前用户”的措辞。影响规范与 ACL 验收范围。

此外须明确函数只处理目标对象，还是递归处理现有子项；当前参考命令没有 `/T`，不能据此承诺递归清除。

## 准备测试

- 按 SID 读取 ACL，不用英文组名匹配，兼容中文版 Windows。
- 预置显式授权，避免只测默认继承 ACL 而错误通过。
- 验证当前用户仍能读写，缺失路径保持缺失。
- 所有变更限定在 pytest 自己创建的临时对象。

- 关闭条件：目标权限模型与测试一致，参考步骤能达到该模型，失败能恢复测试对象。
- 决定：待填写。协调者确认前不按原参考命令宣称权限收紧成功。
