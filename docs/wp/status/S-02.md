## 公开接口与消费者交接

- `base.py` 是权威接口，`engine.py` 再导出同一对象；所有 06 §6.1 输入输出字段保留原名。
  数据类 frozen；EvidenceScore 保持 `list[float]` 字段，复制输入并拒绝常规列表修改，
  copy/deepcopy 支持不可变对象。取消是结构 Protocol，不导入 rpc。
- S-03/S-04 实现 `score_pairs`，仅返回显式请求 pair；不得扩张未请求组合、返回部分结果。
  `cartesian_pairs` 提供全量包装所需的组合；fake 的 `score_event` 只调用一次 `score_pairs`。
  `JEV_CONCURRENCY=4`，本包不实现网络、SDK 重试或 DuckDB 扩展加载。
- `QuestionSpec(instructions,true_text,false_text)` 固定 `type="noul"`；问题集
  `qs-2026-11-02.2`，`YES=0.7 / NO=0.3 / PACK_THESES=True` 均为既定开发默认。
  direct 评分 PREFIX、五题和 criteria 与主审 `scripts/probe_jev.py` 快照逐字比较；
  direct 证据对三种关系、有无失效条件共六种分支比较 G0 实际构造函数，使用无反引号文本。
- JEVDB 评分前缀、五题、criteria 和证据使用完整独立模板，直接引用实际 STRUCT 字段
  `thesis/kill_condition/document`，不替换 direct 模板；foreign path 或未渲染占位符报错。
  `validate_ref`、`validate_question_name` 可供响应适配层复用。
- 逻辑数 1–5、statement 1–500、非空 kill_condition ≤300、非空 passage ≤1200，按 Unicode
  码点计数；证据构造 1–40 句。None kill 省略评分题；不把用户文字或阈值拼进模板。
- classify 的 13 行真值表及 headline 均断言；优先次序是相关性、推翻、削弱、待确认、支持、无关。
  `kill_met=None` 不参与最大值或待确认信号。概率与阈值拒绝 bool、NaN、inf、越界与非数值；
  阈值还要求 `0 <= no < yes <= 1`，非法输入 `ValueError` 交由 S-05 映射。
- `estimate_tokens=(chars*2+6)//7`，`reserve_tokens=(raw*6+4)//5`；所有计数拒绝 bool、
  负值和非整数。`BudgetDecision.remaining=max(limit-used,0)`，不在这里扣减预算。
- `load_price_table(path)` 返回精确 model ID 到 Decimal 单价；`cost_usd` 六位 HALF_UP，
  独立 Context 隔离全局 precision/rounding/traps/flags，未知 model 拒绝，不按零计费。
  models 必须是非空 dict，model ID 必须是 `jev-<major>.<minor>.<patch>` 固定版本，
  每行必须是 dict 且包含 ASCII Decimal 文本 input_usd_per_mtok。
  bool、float、int、空值、非法文本及非有限/负价格均抛 ValueError；允许显式字符串零价。
  一行非法使整个加载失败，不返回部分表；其余来源/生效日元数据不参与价格转换。
  `009_usage.sql` 与 04 §3.9 DDL 逐字比较；本包仅提供 migration，没有主动创建数据库。
- `EngineFactories(jevdb,jev_direct)` 由组合根注入；`EngineSelection(engine,changed)`，
  `EngineChange(from_engine,to_engine,reason)`。auto 只在 `EngineError(ENGINE_UNAVAILABLE)`
  后构造一次 direct，其他错误原对象传播；显式 jevdb 不降级。
- fake 提供 score/evidence 调用数、requested/completed pair 数与请求快照，以及注入错误、
  中途取消和 fail_after 的全批失败。所有 fake 概率是 synthetic，不是模型录制或验收数据。
