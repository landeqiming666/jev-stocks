### Python 与 ECMAScript 的精确规则

Python `str.strip()` / `str.isspace()` 共有 29 个空白字符。本次用显式字符类，避免直接使用 Node 的 `\s`：

```text
[\u0009-\u000D\u001C-\u0020\u0085\u00A0\u1680\u2000-\u200A\u2028\u2029\u202F\u205F\u3000]
```

Python 会 strip U+001C–001F 和 U+0085，Node `\s` 不会；U+FEFF 在 Node `\s` 中但不被 Python strip，本次不把它列入空白。U+200B 同样不按空白移除。

所有正则使用起始 `^` 与绝对结束条件 `(?![\s\S])`；不依赖 `$` 在末尾换行前也能匹配的语义。只有首尾显式空白不限长度；核心长度有界。内部文本用匹配任意码点的原子，含换行也计入长度。原子使用确定的 UTF-16 surrogate-pair 分支，令 Node 默认 RegExp 将合法 astral 字符视为一个码点；Python 与 Node `u` 模式也按一个码点匹配。该表达用于 UTF-8 JSON 字符串，不需自定义格式、标记或关键词。

- key 核心为 1–512 个非空白码点。
- statement 核心首尾必须非空白，总长度 1–500；kill 使用同类可空核心，总长度 0–300。
- email 核心先通过最多 120 个码点的 lookahead，再使用原 `非 @ / 非空白 + @ + 非 @ / 非空白 + 点 + 非 @ / 非空白` 形状；全空白单独可空。
