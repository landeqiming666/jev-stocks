| `holdings.upsert` | `{instrumentId,quantity,avgCost,note}`；数量/成本保持 Decimal 字符串，备注按 Python strip 码点规范化；成功重新查询并滚动到新行 |

| `thesis.create` | `{instrumentId,statement,killCondition}`；模板只填入编辑器；成功才 onSaved |

| `thesis.archive` | `{thesisId}`；Modal 二次确认，成功重新查询逻辑和持仓状态 |

数量与成本采用机器契约及真实 portfolio 服务的 `0..99999999999999.9999`、最多四位
小数、无科学计数法、无多余前导零约束，禁止经过 Number 转换。展示数量通过字符串
分组；金额复用已验收的 BigInt formatMoney。计算市值读服务器字符串，不施加数量的
14 位整数上限。数量为零显示「关注」，真实服务要求此时成本必须为空，前端明确校验。

正文/失效条件/备注分别 500/300/200 个 trim 后 Unicode 码点。自有 PortfolioField
复用 U-01 的控件和样式，但使用明确 count 值，因为公共 Field 会按 JS trim 从 value
重算，不能准确覆盖 Python strip 的 U+0085/U+001C。这个差异只在自有文件解决。
保存时空 kill/note 转 null；超限立即 aria-invalid 和字段说明。Cmd/Ctrl+Enter 保存、
Esc 取消；有草稿则确认。行 Enter/Space 展开，aria-expanded/controls 同步；关闭编辑器
归还对应编辑/添加入口焦点，Modal trap/Esc 复用 U-01。确认、关闭的 RAF 在卸载清理。

冲突刷新单独展示服务器当前版本及正文，保留两个输入字段；保存仍禁用。用户明确点击
「以第 N 版为基础保存当前输入」后，只更新 expectedVersion，下一次保存仍走乐观锁。
服务器不存在/已归档时保留输入并提示关闭。路由、同页行切换、刷新/关闭窗口有未保存
退出护栏；保存中保持在当前页并通过 Toast 提示。请求序列、查询/搜索/行情取消、通知
和退出监听均在对应组件卸载清理。

行情标题来自实际各行收盘日期的最早日，不把 holdings.list 的查询时间或失败请求时间
伪装成行情截至日。部分失败显示更新数量、每一失败标的及其自己的旧日期；全部请求
失败时保留旧表格，缓存为空时明确显示本地没有收盘价。所有状态标签和最近判定均来自
真实返回字段，没有自行生成判定或用 mock 覆盖生产结果。
