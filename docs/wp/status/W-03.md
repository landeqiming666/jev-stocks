## 实际复现与诊断

首次 vcpkg 安装的 jom 把中文工作区目录转换成问号，生成文件失败。在同一物理工作区内使用临时 ASCII 盘符后，固定的 OpenSSL Debug 和 Release 均构建成功。Windows tar 在两个中文 CSV 文件名处报错，改用 Python 3.12 解包后两套源码进入 CMake。DuckDB 的两个未启用测试 symlink 由解包器单独省略。

首次 MSVC 编译在 http_retry.hpp 第 54 行因 timegm 返回 C3861，驱动报告 COMPILE、退出 31。通过 JEVDB 的 CMake 项目钩子，只为 jevdb_loadable_extension 定义 timegm=_mkgmtime，沿用原源码和 UTC 转换语义，离线重编通过。[Microsoft CRT 文档](https://learn.microsoft.com/en-us/cpp/c-runtime-library/reference/mkgmtime-mkgmtime32-mkgmtime64?view=msvc-170)
