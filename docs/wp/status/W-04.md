跨新进程读取已验证。凭据管理器前后截图尚待采集。C-07 生产装配上线后再验证实际应用启动链路，当前 RPC 验收从 C-04 的注入点接入。

Windows 原生 `CredReadW` 另外定向复核了一个随机测试条目。写入前无记录，写入后持久化标志为本机，删除后再次查询无记录。记录位于工作区 `tmp/w04-native-system-proof.json`。

C-07 的 Windows 装配可通过 `KeyringSecretStore(backend=WindowsCredentialBackend())` 接入已验证的适配器。设置页验收使用空白专用 Windows 用户和假凭据，记录保存、重启后状态与清除，并截取本次测试条目在凭据管理器中的变化。
