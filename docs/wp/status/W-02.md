## 真实核心验收入口

新增的 Windows 用例通过 C-02 启动真实 `python -m sentinel`，验证离线 `app.bootstrap` 和三秒内退出码为 0。默认套件 7 项通过，真实核心用例按条件跳过。显式运行用例已核对会报告当前缺少的 C-07 文件。

C-07 就绪后，在禁用联网、没有 Sentinel 凭据的专用 Windows 测试账户中，从 `apps/desktop/src-tauri` 执行以下命令。

```powershell
$env:SENTINEL_WINDOWS_DISPOSABLE_PROFILE = '1'
cargo test --locked --offline --test bridge_windows test_real_core_accepts_bootstrap_on_windows -- --ignored --exact
```

设置同一环境变量后，Windows 验收脚本会在检测到 C-07 时自动执行该用例。
