- 四个规定模型完整实现；FetchedEvent 额外提供可选 title、fetched_at、warnings，前三个规定参数仍兼容。
  Repository 增加 `get(ref)` 支持复用，返回已存标题/时间/正文及从 failed 文件恢复的 FILE_FAILED 告警。
  主文档名与 CIK 从已存 URL 恢复，避免新元数据与旧正文错配；跨标的同事件返回 CONFLICT。
- `SecFilingsClient(http, *, email_provider=None)` 每次 list/index/file 请求重新调用 provider，
  复用 `sentinel.domain.contact.is_valid_sec_email`；发送 `Sentinel/<__version__> <邮箱>`。
  缺配置先抛 CONFIG_REQUIRED、missing=[secEmail]，HTTP 调用数为零；客户端不导入 settings。
- submissions 校验全部 16 个必需 list 数组等长；非 JSON 由 D-01 INVALID_JSON 原样传播，
  非 object/缺 recent/数组不齐/非法支持表单行是 SOURCE_UNAVAILABLE/SEC_SCHEMA。
  限 8-K/8-K/A/6-K，时区转 UTC，先 future clamp 到 fetched_at，再取 `since < published_at <= until`，
  返回时间升序；保留 accession 连字符，空 items/description 转 None，不猜历史分页需求。
- URL 只允许 HTTPS www.sec.gov archive，CIK 为 1..9999999999 的 ASCII 数字，
  accession 为十位-两位-六位数字，文件名为安全单段 ASCII。
  在 urljoin 前阻断路径穿越、反斜线、编码路径、控制字符、空链接；拒绝外部主机、凭据、端口、query/fragment。
  索引链接必须属于当前 CIK/accession 目录；三种已限定 ixviewer 路径只接受唯一 doc 参数，
  其值必须是同目录 archive 路径，转成直接 archive URL 后验证。HTML 本身不会触发任何请求。
- Lexbor 读取第一个包含四个规定表头的索引；无表格退主文档并告警，非法 seq/链接跳过并固定英文告警。
  主文档强制 seq=0，按 SEC seq 选择最多三个 HTML EX-99，其他文件记录 skipped、没有 HTTP。
  重复 seq/文件名或非主文件占 seq=0 明确 SEC_INDEX_CONFLICT；服务按索引异常退主文档并返回 INDEX_CONFLICT。
- HTML 使用已锁 `selectolax.lexbor.LexborHTMLParser`；删除 script/style/head/noscript，
  注释不进入 text；块级换行、表格 ` | `、Inline XBRL 仅保留文字。
  scripting=True 只改变 Lexbor 的 noscript 分词，不执行脚本；避免 head noscript 文字被移到 body。
  应用 NFC、控制字符删除、NBSP/空白折叠，按 Unicode 码点截到 200000 并固定告警。
- 标题包含 16 个文档给定 Item 名称，未知项用 Item；8-K/A 用 8-K 前缀。

  Item 措辞只对照仓库规范，未联网独立核实 TODO-VERIFY(D-03)。
- 每文件 SourceError 记 failed/text=None/char_count=None，其他文件继续；有正文 full_text，
  无正文且发生文件或索引网络失败 fetch_failed，正常全空 title_only。
