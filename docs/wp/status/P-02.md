## API 与组合

`sentinel.scan.ScanService` 构造参数：

```python
ScanService(
    db,
    settings_provider=settings.get,
    key_provider=lambda: secrets.status()["jevKey"],
    holdings_provider=portfolio,
    instrument_provider=instrument_repository.get,
    filings=sec_filings_service,
    pipeline_resolver=resolve_pipeline,
    emit=emit_notification,
    theses_provider=None,
    pending_count_provider=None,
)
```

settings_provider 返回满足本包 SettingsSnapshot 的真实设置对象；内部建立不可变
ScanConfiguration，含 engine/model_id/sec_contact_email/daily_token_budget/
first_scan_lookback_days。resolver 每次 start/retry 接收这一当前快照，返回真实
`DecisionPipeline(db, engine, model_id=..., daily_budget=...)`；验证数据库路径、
固定模型 `jev-1.14.0`、预算和指定引擎一致。不反向 import app/settings/portfolio，
不改问题集。持仓 provider 直接兼容真实 PortfolioService；默认把它的 ThesisView
转换为 S-05 ThesisInput，ref 为 t1 起。可显式注入 theses_provider。

公开业务方法为 `start(market, requested_from=None) -> str`、`cancel(run_id)`、
`status(run_id)`、`history(limit=50, cursor=None)`、`detail(run_id)`、
`retry_batch(batch_id, cancel=None)`。辅助接口为 `recover_on_startup()`、
`before_config_change()`、`configuration_guard()`、`budget()` 和 `wait_idle(timeout)`。
`register_handlers(registrar, service)` 注册 scan.start/status/cancel/history/detail/
retryBatch 六个方法；仅 retryBatch 声明 cancellable=True，timeout_ms=60000。
start 的 RPC 请求不可取消；长期运行使用 scan.cancel。

C-07 必须在迁移完成后、开始接受请求前调用 recover_on_startup 一次，恢复
queued AND running 为 interrupted，不自动续跑。两个活跃 handle 不得互相调用
恢复；已有本进程扫描时恢复返回 CONFLICT。构造、恢复、注册均不默认扫描。

C-04 可注入 before_config_change；它是瞬时检查。C-07 应用
`with scan.configuration_guard():` 包住整次 settings.update/secrets.set/clear 调用，
共享 start/retry 的锁，消除检查与写入之间的竞态。guard 不持有数据库事务。
当前配置变化后下一次 resolver 消费新快照；缺 key/email 返回 CONFIG_REQUIRED。
原运行只有一个 engine 字段；手动重试若当前引擎已改变，返回 CONFLICT/
SCAN_ENGINE_CHANGED 并引导新扫描，避免将不同引擎的实际/估算用量混入原运行。
预算变化仍通过当前 resolver 生效，不要求重启。
历史和本地查询不依赖 key/email。pending_count_provider 由 P-03/C-07 注入，
返回真实待处理数量；未注入时不伪造清单数量，也不 import pending.py。

## 行为与事务

- start 在短事务中检查 queued/running 并创建 ULID queued 行，立即交给 daemon。
  数据库路径/市场共享进程内互斥与数据库事务校验，跨 Database handle 生效。
  新运行、手动重试、配置写入护栏使用同一互斥。
- 首扫完整配置回看，默认 7 天；72 小时只限制已有陈旧水位。显式 from 的
  30 天下限、未来拒绝及带时区归一化均落实，所有存储/输出时刻为 UTC/Z。
- 所有可扫描 issuer 的列表完整成功后才单调推进水位；一份正文失败不改变
  列表覆盖语义。任一 issuer 列表失败不推进水位，其他批仍可交付为 partial。
  列表未补齐的运行不能仅因手动重试现有失败批成功而升为 succeeded。
- 新运行合并最近 30 天失败/预算 pending 事件，按 instrument/event 去重；
  只看该对的最新成功/失败/预算状态，成功后的旧失败不无限重发现。
  同时刻内部排序用运行插入顺序解 ULID 随机尾部的先后，公开 history 仍严格
  created_at DESC/run_id DESC，cursor 为 base64url(UTC时刻|run_id)。
- D-03 的真实恢复接口仍是 fetch_for_instrument(instrument, since=..., until=...)。
  已在本轮发现阶段调用过 D-03 的事件不立刻重复下载；合并的旧事件及手动重试
  先走同一真实恢复路径。fetch_failed 必须失败，不能当成零段成功。
- persist_passages 调用真实 S-01 PassageSplit，按文件 seq 与码点偏移建立确定性
  ID、规范化 hash；每文件最多 60 段、每段最多 1200 码点，S-05 每批最多判前
  60 段。永久 passage 插入幂等且回读核对整行，不覆盖旧正文或引用。
  title_only 使用 file_seq=-1 的标题段；只有正常无标题/文字事件可零段成功并告警。
- 网络、分段、provider、模型都在写事务外；写后读取用原 tx。S-05 调用完整
  BatchContext(run_id,batch_id,event_id,instrument_id,company)，不伪造五参数接口。
- S-05 按 used_today + reserve_tokens(raw) 的 20% 余量执行预算。当前预算批保持
  pending，后续 pending 带预算错误并停止调度；已成功则 partial，否则 failed。
- 批统计以真实已提交 decision/usage_daily 差额累计，包含评分第一事务后取消
  仍留下的判定与 usage；当前批保持非 success。actual/estimated 都进入 inputTokens，
  requests 为 score_pairs/证据的逻辑调用数，缓存零新增用量。费用按总 token
  重新计算 Decimal 六位小数，避免逐批舍入丢失费用。
- 取消在 queued、发现调用前后、落段前后、批边界、流水线和最终批状态写入前检查。
  已提交保留；manual retry 的 60 秒总期限包含配置/resolver 准备和市场锁等待，
  可由请求 token 或 scan.cancel 取消；准备失败不改变原批次。
  超时/取消返回后，未退出的外部调用仍占市场互斥，迟到成功不写成成功批。
- 错误只保留机器码和受限配置/字段/原因数据，不输出原异常、SQL、正文、key/email。
  scan.progress 同 run 至少 500 ms（重试不重置），inbox.updated 至少 1 秒、
  budget.updated 至少 2 秒。scan.finished 每运行一次，在最后一次 progress 后；
  手动重试更新原运行，不重复 finished。

## 局限与组合要求

D-03 没有 CancelToken 参数，P-02 无法中断它正在执行的请求或内部文件循环，
只在真实 fetch_for_instrument 前后检查。重试同步等待有界，但后台调用可能稍后才退出；
退出前保持互斥，配置更改冲突。S-05 自身已批准的两事务限制仍适用：不能撤回外部
token，取消/失败时仅提交 ledger 中的用量可计数，未提交证据请求的外部费用不能声称零。
requests 不是 SDK 内部 HTTP 尝试数。

usage_daily 没有 run/batch 列，当前差额归属依赖 C-07 让同库同市场的生产流水线调用
全部经过本服务；不要绕过互斥直接并发 process_batch。resolver 创建和关闭引擎、
注入真实 pending provider、核心初始化恢复、公共中文模板注册与整次配置调用 guard
均由 C-07/主 Agent 在组合根落实，本包未改公共 initializer 或伪造这些已组合。
