## 接口与行为

- 公开接口及 frozen dataclass 字段遵循 S-01 §5.1；空文本和全空白文本不产出 span，`original_chars` 始终为 `len(input)`。
- 所有偏移是 Python Unicode 码点下的左闭右开索引，span 直接取 `original[start:end]`；仅调整边缘空白的索引，内部空白、换行和标点不改写。
- 固定缩写表覆盖全部 18 项并忽略大小写；多句点缩写的内部句点也受到保护，ASCII 数字之间的小数点不切句。
- 句末先合并连续标点与闭合符，再根据后续大写、数字、开引号/括号、CJK 或文末判断边界；双换行始终切句、切段。
- 段落优先拼完整句，长句在窗口后半段优先寻找最后一个空格、制表符或换行，再按码点硬切；短尾可以继续与后句拼段。
- `max_chars` 接受整数 `100..1200`，`max_passages` 接受整数 `1..60`；非 str 输入、非 int 限制及 bool 都明确抛出对应字段名的 `ValueError`，空文本也校验参数。
- 达到数量上限时，从最后已提交 span 的 end 检查剩余原文；仅当仍存在非空白正文才设 `truncated=True`。
- 生产模块只导入标准库 dataclasses，无 I/O、环境变量、网络或数据库访问，无新增依赖。

## 规范解释与边界风险

- §6.1 的 `no.` 缩写例外与 §8.1 的 `He said "no." Then left.` 基线存在冲突。按要求满足基线：句点紧跟闭合符时允许句末判断，闭合符优先于缩写例外；其余缩写保持固定表规则。
