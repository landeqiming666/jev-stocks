## 交付内容

| 路径 | 职责 |
|---|---|
| `scripts/acceptance.py` | M-1～M-8 编排、证据落盘、`acceptance.json` + `summary.md`、`--self-test` |
| `apps/desktop/e2e/acceptance/playwright.config.ts` | 串行验收场景（1470） |
| `apps/desktop/e2e/acceptance/acceptance.spec.ts` | 离线六页可读、1024 无横向滚动、密钥不回显、重启保留结果、演示脚本 ≤300s |
| `apps/desktop/e2e/acceptance/demo-script.ts` | 10 段 5 分钟演示脚本与降级方案 |
| `apps/desktop/e2e/acceptance/manual-checklist.md` | 录屏、键盘、断网、取消/重启、密钥五项人工证据 |
| `apps/desktop/e2e/acceptance/report.schema.json` | 报告字段约束，`--self-test` 会校验 |

CLI：`python3 scripts/acceptance.py [--offline|--full] [--report-dir PATH] [--skip-e2e] [--skip-gate] [--json] [--self-test]`。
默认 `--offline`，M-8 固定 `not_run`，因此整体 `fail`——这是诚实结果，不是缺陷。

python3 scripts/acceptance.py --self-test

python3 scripts/acceptance.py --offline --skip-e2e --skip-gate
# ACCEPTANCE FAIL 5/8：M-1/M-3/M-4/M-5/M-6 pass，M-2/M-7/M-8 not_run

cd apps/desktop && pnpm exec playwright test -c e2e/acceptance/playwright.config.ts
# 4 passed（六页离线、密钥不回显、重启保留、脚本 ≤300s）

python3 scripts/check.py
# 16 通过 / 0 失败 / 1 跳过

各项证据：M-1 演示计数 6/5/6/6/12/1560；M-3 日志、DuckDB 文本列与 bootstrap 输出均无密钥，
植入密钥可被同一扫描器检出；M-4 12 条判定均有 engine/model/questionSet/evidenceKind 且在白名单；
M-5 synthetic 回放 30 样本、strict F1 0.80；M-6 缺证据判定不进入清单；M-7 全量门禁通过。
