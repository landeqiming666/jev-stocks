# Thesis Sentinel · 投资逻辑哨兵

> 不推荐股票，只守住你买入的理由。

给持有 3–20 只美股、会自己写投资理由、但没时间天天读公告的个人投资者：**一个本地运行的投资逻辑监控器**。你写下买入理由，它每天只挑出真正动摇这些理由的披露，并附上原文。它不荐股、不预测、不替你决策。

## 为什么需要它

- **券商推送按“股票”订阅，不按“你的理由”过滤。** 一只股票一个月十几条公告，最后你关掉提醒，重要变化也跟着漏掉。
- **买入理由散落在脑子里、聊天记录和备忘录里。** 几个月后只能看到盈亏，看不到“当初为什么买、现在是否还成立”。
- **AI 投研工具替你做结论。** 结论会翻转、依据难追溯，用户不敢拿它守持仓。

Thesis Sentinel 把这三件事连起来：**记录判断 → 监控前提 → 留下证据 → 复盘决策。**

## 怎么工作

```text
写下投资逻辑
   ↓
抓取持仓相关披露（SEC 8-K / 6-K）
   ↓
Jev 逐段判断：无关 / 支持 / 削弱 / 推翻
   ↓
只把“削弱 / 推翻”放进今日清单，附原文证据
   ↓
你选择：仍然成立 / 修正逻辑 / 准备卖出 / 忽略
   ↓
形成可复盘的投资逻辑时间线
```

没有需要处理的事情时，它明确告诉你：**“今天没有需要处理的变化。”**

## 它不是什么

- 不是选股器，不帮你找新股票
- 不是荐股工具，不给目标价和收益预测
- 不是股票问答聊天框
- 不是券商交易终端，不接真实下单

## 课程背景

本项目是《矩阵分析》课程题目二的原型：基于 JEVDB 的股票研究与模拟交易软件。JEVDB 的语义判定用于“披露 × 投资逻辑”的匹配；模拟交易与组合风险模块用于复盘与课程验收，不构成本产品的核心定位。

公开仓库不包含 API 密钥、真实持仓和未脱敏的用户数据。
